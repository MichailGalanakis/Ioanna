# あ 日本語 — Ιαπωνικές Ασκήσεις Λεξιλογίου

Μια απλή εφαρμογή που δημιουργεί **ασκήσεις** από τις δικές σου ιαπωνικές λέξεις:

- ✅ **Πολλαπλής επιλογής**
- ✅ **Αντιστοίχιση** (match)
- ✅ **Συμπλήρωση κενού** (πληκτρολόγηση)

Δουλεύει σε **κινητό και υπολογιστή**, **εγκαθίσταται** σαν κανονική εφαρμογή, και
λειτουργεί **χωρίς ίντερνετ** (offline). Όλα τα δεδομένα μένουν στη συσκευή σου.

Είναι φτιαγμένη ως **PWA (Progressive Web App)** με καθαρά HTML/CSS/JavaScript — χωρίς
εξαρτήσεις και χωρίς βήμα build.

---

## Πώς το χρησιμοποιώ

1. Άνοιξε την εφαρμογή στον browser.
2. Πάτησε **«+ Νέο σετ»** και δώσε ένα όνομα (π.χ. «Κεφάλαιο 1»).
3. Πρόσθεσε λέξεις. Κάθε λέξη έχει τρία πεδία:
   - **Ιαπωνικά** (π.χ. `水`)
   - **Ανάγνωση** (π.χ. `みず` ή `mizu`) — προαιρετικό
   - **Σημασία** (π.χ. `νερό`)
4. (Προαιρετικά) Χρησιμοποίησε τη **Μαζική εισαγωγή** για να βάλεις πολλές λέξεις μαζί,
   μία ανά γραμμή με τη μορφή:
   ```
   水 ; みず ; νερό
   犬 ; いぬ ; σκύλος
   食べる ; たべる ; τρώω
   ```
   (Διαχωριστικό: `;`, `,` ή Tab.)
5. Πάτησε **«Εξάσκηση ▶»**, διάλεξε τύπους ασκήσεων, κατεύθυνση και πλήθος ερωτήσεων.
6. Στο τέλος βλέπεις το **σκορ** και ανασκόπηση των απαντήσεων.

> Θες να δοκιμάσεις γρήγορα; Στην αρχική πάτησε **«Φόρτωσε δείγμα λέξεων»**.

### Κατευθύνσεις άσκησης
- Ιαπωνικά → Σημασία
- Σημασία → Ιαπωνικά
- Ιαπωνικά → Ανάγνωση
- Ανάμεικτα

Στη **συμπλήρωση κενού** γίνονται δεκτές εναλλακτικές σημασίες χωρισμένες με `/` ή `,`
(π.χ. `γεια / καλημέρα`). Όταν η ζητούμενη απάντηση είναι τα ιαπωνικά, γίνεται δεκτή και
η ανάγνωση (π.χ. `みず`).

## ⭐ Ο πιο εύκολος τρόπος: ένα αρχείο, χωρίς τίποτα άλλο

Υπάρχει έτοιμο το αρχείο **`Ιαπωνικές-Ασκήσεις.html`** — είναι ολόκληρη η εφαρμογή σε
**ένα μόνο αρχείο** (~45 KB).

1. Κατέβασέ το στη συσκευή σου.
2. Άνοιξέ το με **διπλό κλικ** (ή «Άνοιγμα με → browser»).
3. Παίζει **κατευθείαν** — χωρίς GitHub, χωρίς server, χωρίς ίντερνετ.

Λειτουργεί σε υπολογιστή (Chrome, Edge, Firefox, Safari) και μπορείς να το στείλεις και
στο κινητό σου (π.χ. με email/Drive) και να το ανοίξεις από εκεί. Τα σετ λέξεων
αποθηκεύονται τοπικά στον browser.

> Το αρχείο φτιάχνεται από τον πηγαίο κώδικα με: `node build.js`
> (Δεν χρειάζονται βιβλιοθήκες — μόνο Node.)

> Σημείωση: όταν το ανοίγεις ως τοπικό αρχείο (`file://`), δεν προσφέρεται η
> «εγκατάσταση ως εφαρμογή» (PWA) — γι' αυτό χρειάζεται φιλοξενία σε URL, δες παρακάτω.

## Εναλλακτικά: εγκατάσταση ως κανονική εφαρμογή (PWA)

Αν θες εικονίδιο στην αρχική οθόνη και πλήρη offline λειτουργία ως «εφαρμογή», η εφαρμογή
πρέπει να είναι διαθέσιμη σε μια διεύθυνση (URL). Ο πιο εύκολος δωρεάν τρόπος είναι το
**GitHub Pages**.

### Βήμα 1 — Δημοσίευση με GitHub Pages
1. Στο GitHub: **Settings → Pages**.
2. Στο **Source** διάλεξε **Deploy from a branch**.
3. Branch: `claude/japanese-vocab-exercises-yUE0E` (ή κάνε merge στο `main`), φάκελος `/ (root)`.
4. Πάτησε **Save**. Μετά από λίγο θα εμφανιστεί η διεύθυνση, κάτι σαν:
   `https://<το-username-σου>.github.io/ioanna/`

### Βήμα 2 — Εγκατάσταση στο κινητό
- **Android (Chrome):** Άνοιξε τη διεύθυνση → μενού **⋮** → **«Προσθήκη στην αρχική
  οθόνη»** / «Install app». (Ή πάτησε το κουμπί **«Εγκατάσταση»** πάνω δεξιά στην εφαρμογή.)
- **iPhone/iPad (Safari):** Άνοιξε τη διεύθυνση → κουμπί **Κοινή χρήση** (□↑) →
  **«Προσθήκη στην οθόνη Αφετηρίας»**.

### Βήμα 3 — Εγκατάσταση στον υπολογιστή
- **Chrome / Edge:** Άνοιξε τη διεύθυνση → εικονίδιο εγκατάστασης στη μπάρα διευθύνσεων
  (ή το κουμπί **«Εγκατάσταση»** μέσα στην εφαρμογή).

Μετά την εγκατάσταση, η εφαρμογή ανοίγει σαν κανονικό πρόγραμμα και δουλεύει **offline**.

## Τοπική εκτέλεση (για δοκιμή στον υπολογιστή)

Η εφαρμογή χρειάζεται έναν τοπικό web server (όχι άνοιγμα του αρχείου με `file://`,
επειδή ο service worker και το `fetch` του δείγματος απαιτούν `http`):

```bash
# Με Python
python3 -m http.server 8099
# άνοιξε: http://localhost:8099/

# ή με Node
npx serve .
```

## Δομή έργου

```
Ιαπωνικές-Ασκήσεις.html # ⭐ Αυτόνομη έκδοση ΕΝΟΣ αρχείου (διπλό κλικ → παίζει)
build.js                # Φτιάχνει το παραπάνω αρχείο από τον πηγαίο κώδικα
index.html              # Διεπαφή / όλες οι οθόνες (έκδοση πολλών αρχείων)
css/styles.css          # Εμφάνιση
js/sample-data.js       # Ενσωματωμένο δείγμα λέξεων
js/storage.js           # Αποθήκευση σετ λέξεων (localStorage)
js/exercises.js         # Δημιουργία ασκήσεων
js/app.js               # Λογική διεπαφής & πλοήγηση
manifest.webmanifest    # Ρυθμίσεις PWA (όνομα, εικονίδια)
sw.js                   # Service worker (offline)
data/sample-deck.json   # Δείγμα λέξεων (για την έκδοση με server)
icons/                  # Εικονίδια εφαρμογής
```

## Δεδομένα & ιδιωτικότητα
Όλα τα σετ και οι λέξεις αποθηκεύονται **τοπικά** στον browser/συσκευή σου
(`localStorage`). Τίποτα δεν στέλνεται σε κάποιον server. Μπορείς να κάνεις
**Εξαγωγή/Εισαγωγή (JSON)** για αντίγραφο ασφαλείας ή μεταφορά σε άλλη συσκευή.
