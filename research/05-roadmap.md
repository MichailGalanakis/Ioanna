# 05 — Roadmap

Σταδιακό πλάνο με **gates**: κάθε φάση έχει κριτήρια που πρέπει να περαστούν
πριν προχωρήσουμε. Αν ένα gate αποτύχει, δεν προχωράμε — επιστρέφουμε ή
σταματάμε.

---

## Φάση 0 — Θεμέλια (2–3 εβδομάδες)

**Στόχος:** υποδομή που δεν αγγίζει χρήματα.

- [ ] Setup repo, Postgres + TimescaleDB, schema του journal
- [ ] **Governor πρώτος** — όλα τα όρια, kill switch, μοναδιαία tests
- [ ] Data ingestion: ccxt για crypto, funding rates, historical OHLCV
- [ ] Validation module: Deflated Sharpe, PBO, Purged K-Fold, CPCV
- [ ] Trial registry — καταγράφει κάθε δοκιμή από την πρώτη μέρα
- [ ] Grafana dashboard

**Gate 0:** Ο Governor απορρίπτει σωστά κάθε παραβίαση ορίου σε tests. Το
validation module αναπαράγει γνωστά αποτελέσματα σε συνθετικά δεδομένα
(τυχαία στρατηγική → DSR κοντά στο 0).

> Αν το validation module δείχνει υψηλό DSR σε τυχαίο θόρυβο, είναι λάθος
> υλοποιημένο και **όλα τα υπόλοιπα είναι άχρηστα**.

---

## Φάση 1 — Passive core (1–2 εβδομάδες)

**Στόχος:** το 70% να δουλεύει, γιατί αυτό είναι που πραγματικά μετράει.

- [ ] Επιλογή UCITS ETF (accumulating, χαμηλό TER, φορολογικά αποδοτικά)
- [ ] Αυτοματοποιημένο DCA
- [ ] Rebalancing logic με κατώφλια (όχι ημερολογιακό — μειώνει συναλλαγές)
- [ ] Φορολογική παρακολούθηση για το Ε1

**Gate 1:** Τρέχει αυτόνομα για 1 μήνα χωρίς παρέμβαση. Καμία λανθασμένη
εντολή.

> Αυτή η φάση είναι «βαρετή» και είναι σκόπιμα πρώτη. Αν το σύστημα δεν
> μπορεί να κάνει αξιόπιστα DCA σε ETF, δεν έχει καμία δουλειά να αγγίξει
> perpetual futures.

---

## Φάση 2 — Research agents (3–4 εβδομάδες)

**Στόχος:** το AI ερευνά και τεκμηριώνει. **Καμία εκτέλεση.**

- [ ] Ingestion Agent
- [ ] Analysis Agent → δομημένες προτάσεις
- [ ] Devil's Advocate Agent
- [ ] Risk Agent με fractional Kelly
- [ ] Journal integration — κάθε πρόταση καταγράφεται πλήρως
- [ ] **Shadow mode**: το σύστημα προτείνει, τίποτα δεν εκτελείται, τα
      αποτελέσματα παρακολουθούνται σαν να είχαν εκτελεστεί

**Gate 2:** 3 μήνες shadow mode. Οι προτάσεις αξιολογούνται με deflated
μετρικές, **συμπεριλαμβανομένου ρεαλιστικού slippage και fees**.

Κριτήριο: **DSR > 0.5 σε shadow mode.** Αν όχι, το πρόβλημα είναι στη
στρατηγική, όχι στην υλοποίηση — επιστροφή στην έρευνα.

> Εδώ θα φανεί η αλήθεια. Το Alpha Arena έδειξε ότι τα fees τρώνε το PnL
> από υπερ-συναλλαγές — αν αυτό συμβεί στο shadow mode, θα το δούμε δωρεάν.

---

## Φάση 3 — Πρώτο live κεφάλαιο (3–6 μήνες)

**Στόχος:** πραγματικά χρήματα, ελάχιστο ποσό, ένας πυλώνας.

- [ ] Funding-rate arbitrage, **delta-neutral**
- [ ] Ξεκίνημα με **€500–1.000** — αρκετά για πραγματικό slippage, αρκετά
      λίγα ώστε η ολική απώλεια να μην έχει σημασία
- [ ] Ένα exchange πρώτα, μετά δεύτερο
- [ ] Execution layer με idempotency και reconciliation
- [ ] Ημερήσιο reconciliation report

**Gate 3:** 6 μήνες live. Κριτήρια:
- Θετικό PnL μετά από **όλα** τα κόστη
- Max drawdown εντός των ορίων του Governor
- Μηδέν execution incidents (λάθος μέγεθος, διπλές εντολές, αποτυχία reconciliation)
- Το πραγματικό slippage εντός 20% της εκτίμησης του shadow mode

> Το τελευταίο κριτήριο είναι το πιο διαγνωστικό. Αν το πραγματικό slippage
> είναι πολύ χειρότερο από την εκτίμηση, το μοντέλο κόστους είναι λάθος και
> **κάθε προηγούμενο backtest ήταν αισιόδοξο**.

---

## Φάση 4 — Επέκταση (συνεχής)

Μόνο μετά από επιτυχές Gate 3.

- [ ] Σταδιακή αύξηση satellite κεφαλαίου (μόνο μετά από αποδεδειγμένη απόδοση)
- [ ] Copy Trading Analyzer ως research module
- [ ] Exploratory πυλώνας: prediction markets, 5%
- [ ] Αυτόματα post-mortems και ανατροφοδότηση στη στρατηγική

**Gate 4:** Κάθε νέος πυλώνας περνάει το ίδιο μονοπάτι: shadow → μικρό live →
6 μήνες → αξιολόγηση. **Καμία εξαίρεση, όσο καλή κι αν φαίνεται η ιδέα.**

---

## Χρονοδιάγραμμα

| Φάση | Διάρκεια | Σωρευτικά | Κεφάλαιο σε ρίσκο |
|---|---|---|---|
| 0 — Θεμέλια | 2–3 εβδ. | ~1 μήνας | €0 |
| 1 — Passive core | 1–2 εβδ. | ~1,5 μήνας | Το core (χαμηλού ρίσκου) |
| 2 — Research + shadow | 3–4 εβδ. + 3 μήνες | ~5 μήνες | €0 |
| 3 — Πρώτο live | 6 μήνες | ~11 μήνες | €500–1.000 |
| 4 — Επέκταση | Συνεχής | — | Σταδιακά |

**Ρεαλιστικά: ~1 χρόνος πριν το σύστημα διαχειρίζεται ουσιαστικό ενεργό
κεφάλαιο.**

Αυτό δεν είναι υπερβολική συντηρητικότητα — είναι η συνέπεια των δεδομένων.
Το Alpha Arena έδειξε ότι frontier μοντέλα χάνουν 63% σε λίγες εβδομάδες.
Το AIEQ υστερεί του δείκτη οκτώ χρόνια. Η βιασύνη εδώ κοστίζει χρήματα.

Το **passive core δουλεύει από τον πρώτο μήνα** — δεν χάνεις απόδοση όσο
χτίζεται το υπόλοιπο.

---

## Πώς μοιάζει η αποτυχία

Ορίζεται εκ των προτέρων, ώστε να μην ορθολογικοποιηθεί αργότερα:

| Σήμα | Ενέργεια |
|---|---|
| Gate 2 αποτυγχάνει δύο φορές | Η στρατηγική δεν έχει edge. Αλλαγή πυλώνα, όχι παραμετροποίηση |
| Gate 3 αρνητικό PnL μετά 6 μήνες | Σταμάτημα του satellite. Το core συνεχίζει |
| Drawdown > 15% | Auto-halt από Governor. **Δεν παρακάμπτεται χειροκίνητα** |
| Execution incident | Άμεσο σταμάτημα, root cause analysis πριν την επανεκκίνηση |
| Το DSR πέφτει κάτω από 0 για 3 μήνες σε live | Ο πυλώνας κλείνει |

> Ο πιο συνηθισμένος τρόπος να χαθούν χρήματα δεν είναι μια κακή στρατηγική.
> Είναι μια κακή στρατηγική που δεν σταμάτησε στην ώρα της, επειδή «τώρα θα
> γυρίσει». Ο Governor υπάρχει ακριβώς για να μην είναι αυτή η απόφαση δική
> σου τη λάθος στιγμή.
